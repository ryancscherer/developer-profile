# Scherer Developer

Ryan's personal landing page. Built with [Astro](https://astro.build), no framework beyond that,
plain CSS custom properties for the design system (no Tailwind, no component library).

The page tells one story: two real ideas, resolving into simple features, into two real shipped
apps (Vicki the Manager, Pop Shot), then how the work actually happens, then the tech underneath,
last.

See `PRODUCT.md` and `DESIGN.md` for the strategic and visual system this page implements.

## Commands

All commands run from the project root:

| Command           | Action                                      |
| :----------------- | :------------------------------------------ |
| `npm install`       | Install dependencies                        |
| `npm run dev`       | Start the local dev server at `localhost:4321` |
| `npm run build`     | Build the production site to `./dist/`      |
| `npm run preview`   | Preview the production build locally        |
